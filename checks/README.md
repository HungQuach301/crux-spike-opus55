# checks/ — máy kiểm bài thử D (Phiên K, đã khoá)

Chấm mọi yêu cầu gắn nhãn **[MÁY]** trong `BRIEF-D.md`. Yêu cầu **[NGƯỜI]**: `checks/RUBRIC.md`. Artefact phải giao: `checks/CONTRACT.md`.
Khoá: `checks/LOCK` = SHA-256 của toàn thư mục (cách tính ở cuối file). Phiên D không sửa thư mục này; cho rằng luật sai thì ghi `checks-appeal.md`.

## Chạy

```
npm ci; pip install numpy scipy soundfile av faster-whisper      # ffmpeg/ffprobe trên PATH
checks/run.sh            # = node checks/page/sampler.js . ; python3 checks/py/run.py .
checks/selftest/run.sh   # test tự chứng minh: mỗi luật PHẢI trượt fixture xấu và PHẢI đạt fixture sạch
```

Kết quả: `out/checks/report.json` và `report.md`. Trạng thái: PASS | FAIL | MISSING (thiếu artefact — không đạt) | ERROR (luật lỗi — không đạt).
`near` liệt kê mọi chỉ số nằm trong 5% quanh ngưỡng (đầu bài §0 bắt nêu tên trong báo cáo).

Nguyên tắc đo: đo trên file đã giao (khung giải mã từ `out/video.mp4`, âm thanh giải mã, ASR tự chạy — faster-whisper small.en int8 trên bản mix), không tin số khai báo khi đo được; artefact khai báo luôn được đối chiếu với hình/tiếng khi có thể (camera ↔ độ thay đổi hình, tension map ↔ cắt/stem, J/L-cut ↔ ASR, accent ↔ onset nhạc, cắt ↔ đột biến khung).
Luật khung hình chạy qua trang dựng (hợp đồng `window.CHECKS`): đối tượng mỗi 0,1 s; điểm ảnh (mặt nạ lớp chữ / lớp đồ hoạ của trang + khung video đã giải mã) mỗi 0,2 s. Luật bố cục bỏ qua đoạn chuyển động máy đầu cảnh (`scenes[].move`), như bài C.
